# Contributing

Use Python 3.10+ and Node 18+. Run npm install, npm test, start the server, then npm run test:browser (install Chromium with npx playwright install chromium first). Keep visuals and animation intact when changing state transport. Test invalid input, stale timestamps, expiry, and failure recovery. Include before/after screenshots for visual changes using fictional agents only.

Keep credentials, local paths, user photos and real task lists out of patches. Preserve third-party notices. Do not introduce paid API calls without an explicit opt-in design. Contributions must be yours to license under MIT. Describe behavior, validation and limitations in changes.
