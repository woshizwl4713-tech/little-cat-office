---
name: install-little-cat-office
description: Install the local office desktop launcher.
---

Run from the repository root: install Python 3 and Node.js, run `npm install`, then `python3 scripts/catctl.py install-launcher`. Double-click 小猫办公室 on the desktop. Verify http://127.0.0.1:8770/app/. Optionally run `python3 scripts/catctl.py autostart on`. Disable with `autostart off`. Inspect `.local/server.log` on startup failure. Launcher resources are generated by `scripts/launcher.py`; no machine paths are stored in the repository.

> **写入警告 / Writes to the active roster:** 示例 curl 和 `catctl set` 会写入当前运行的办公室名册。演示请启动 `python3 server/server.py --demo --port 8771` 或 `python3 server/server.py --data-dir /tmp/cat-office-demo --port 8771`，并将示例 URL / `CAT_OFFICE_URL` 指向该端口。Examples modify the running office roster; use a demo or temporary data directory and point all clients at its port. 误写可通过名册 UI 或 `POST /api/roster`，请求体 `{"id":"example-id","action":"delete"}` 删除。Delete accidental entries using the roster UI or that API.
